01 · Purpose

Why protocols matter in detection work

A detection pipeline needs stable grouping keys, readable incident output, reliable truth tests, and streaming inputs. Python reaches these capabilities through protocols, invoked by ordinary language syntax and built-ins.

GROUPING

Keys are contracts

dict and set depend on coherent equality and hashes.

OPERATIONS

Logs must explain themselves

A precise repr() makes a failed test or investigation record usable.

STREAMING

Iterables reduce memory

for and iter() consume a protocol, not a particular container.

CORRECTNESS

Implicit calls have reach

Truthiness and comparison can run your code in conditions, collections, and tests.

03 · Core protocols

Small methods, exact promises

MethodUse throughPromise
__init__Class constructionEstablish valid instance state; it returns None.

__hash__hash(x), dict/set membershipEqual hashable objects must have equal hashes.

from collections.abc import Iterator

class EvidenceBatch:
    def __init__(self, records: list[dict[str, object]]) -> None:
        self._records = records

    def __repr__(self) -> str:
        return f"EvidenceBatch(count={len(self)})"  # no raw secrets

    def __len__(self) -> int:
        return len(self._records)

    def __iter__(self) -> Iterator[dict[str, object]]:
        return iter(self._records)

batch = EvidenceBatch([{"status": 401}])
print(repr(batch), len(batch), list(batch))

Use: call repr(batch), len(batch), and iter(batch) (or a for loop), not magic methods directly. Assumption: exposing records via iteration is your intended API. Risk: an iterator over live mutable records lets consumers mutate them unless you document or prevent it.

04 · Keys and comparison

Equality and hashing must describe the same identity

from dataclasses import dataclass

@dataclass(frozen=True)
class RequestKey:
    tenant_id: str
    client_ip: str
    route: str

key = RequestKey("acme", "203.0.113.10", "/login")
counts = {key: 1}
assert counts[RequestKey("acme", "203.0.113.10", "/login")] == 1

A hash table first uses hash(key) to narrow candidates, then equality to resolve collisions. The rule is one-way: if a == b, then hash(a) == hash(b) for hashable objects. Unequal values may share a hash. A value-based __eq__ on a normal class typically makes instances unhashable unless a compatible __hash__ is deliberately supplied; that protects you from a broken key contract.

class RequestKey:
    def __init__(self, tenant_id: str, client_ip: str) -> None:
        self.tenant_id, self.client_ip = tenant_id, client_ip

    def __eq__(self, other: object) -> bool:
        if not isinstance(other, RequestKey):
            return NotImplemented
        return (self.tenant_id, self.client_ip) == (other.tenant_id, other.client_ip)

    def __hash__(self) -> int:
        return hash((self.tenant_id, self.client_ip))

Use: return NotImplemented for an unsupported peer type, allowing Python to try reflected comparison or choose its normal result. Assumption: the tuple contains stable, hashable fields. Risk: returning False for an unknown type can incorrectly suppress another type’s valid comparison behavior.

Never mutate a key after insertionIf a hash/equality field changes after a key enters a dict or set, it can become unreachable at its old hash location. Make key objects immutable (often @dataclass(frozen=True)) and omit mutable fields such as tags, counters, and observed-at lists from their identity.

05 · Truth and iteration

Truthiness is a protocol, not an empty-string shortcut

if value: calls __bool__ when defined; otherwise it may use __len__; otherwise objects are truthy. Use truthiness for a meaningful “has content/is usable” concept. Use an explicit comparison when distinguishing 0, "", [], and None matters.

class FindingSet:
    def __init__(self, findings: list[str]) -> None:
        self._findings = findings
    def __len__(self) -> int:
        return len(self._findings)

if FindingSet([]):       # false because len is zero
    raise AssertionError("unreachable")

limit = 0
if limit is None:        # correct if zero means "disable alerts"
    limit = 100

for record in source: conceptually obtains an iterator with iter(source), repeatedly calls next(iterator), and stops on StopIteration. A container's __iter__ should normally return a new iterator each time; an iterator returns itself. Prefer a generator for straightforward streaming and a class only when it owns meaningful state/protocol behavior.

06 · Dataclass choices

Let the generated methods match the domain

ChoiceGood forTrade-off
@dataclassMutable record with value equalityNormally unhashable; correct if fields can change.
@dataclass(frozen=True)Stable value/keyPrevents attribute rebinding, not mutation inside a nested list/dict.
@dataclass(frozen=True, slots=True)Many small, stable objectsRestricts dynamic attributes; check framework/serialization needs.
eq=FalseIdentity-based objects/resourcesEquality stays identity-oriented; document why.

Do not force unsafe_hash=True to placate a dict/set error. It is only appropriate when you have independently proved that all fields participating in equality remain stable while hashed. A frozen dataclass is often the clearest key, but only if every identity field is itself immutable and semantically stable.

07 · Failure and safety

Keep protocol methods boring, fast, and non-secret

repr(value)

Request developer-facing representation.Use in diagnostics and tests. Assume output may reach logs; omit tokens, headers, and personal data or redact them deliberately.

hash(key)

Inspect a key's hash in a local test.Use to verify equal keys hash equally. Hash values are not stable across Python processes for several built-in types and are not persistence/correlation IDs.

key_a == key_b

Perform value comparison.Use instead of direct __eq__ calls so normal dispatch and NotImplemented handling applies.

for record in batch:

Consume an iterable.Use for streaming. Assume iteration can be repeated only if the object's contract says so; avoid materializing an unbounded source with list().

Version and implementation detailThe data model is language-level, but representations, memory layout, and hash randomization vary by Python version/build and implementation. Never persist hash() output, use it as a security signature, or rely on a particular collision pattern. Python's hash tables are not a substitute for a cryptographic digest.

08 · On the job

Detection-engineering scenarios

GROUPING

Login counters split equivalent clients

Two RequestKey instances represent the same tenant/IP/route but use identity equality, yielding two counters. Define value equality and a matching hash—or use a frozen dataclass—to make the grouping key explicit and test it.

CORRUPTION

A set key changes after insertion

A mutable key includes route, is inserted, then its route is rewritten during normalization. Membership may fail even though the object is present. Keep a separate mutable event and create an immutable grouping key from stable canonical fields.

PRIVACY

An exception logs a bearer token

The default/generated representation includes every field. Give sensitive objects a safe __repr__, or mark sensitive dataclass fields repr=False; verify failure-path logs with sanitized fixtures.

STREAMING

A collector loads an entire capture

A custom wrapper returns a list from an eager property, and callers use it as an iterable. Expose a streaming iterator/generator where appropriate, document one-pass behavior, and test memory on bounded synthetic data.

3. Create an iterable, safe-to-log batch

30 min
class Batch:
    def __init__(self, records): self._records = list(records)
    def __len__(self): return len(self._records)
    def __iter__(self): return iter(self._records)
    def __repr__(self): return f"Batch(records={len(self)})"

print(repr(Batch([{"authorization": "redacted"}])))
