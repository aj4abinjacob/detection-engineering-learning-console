Why it matters

HTTP status, TCP retransmit, IP, and MAC address have distinct collectors and meanings. A detection must state its collector position before it claims a fact.

TCP/IP operational model

Application HTTP, DNS, TLS semantics.
→
Transport TCP/UDP ports and delivery.
→
Internet/link IP routing and local frames.

OSI application/presentation/session broadly map to TCP/IP application; transport to transport; network to internet; data-link/physical to link.

Encapsulation

GET /health HTTP/1.1
Host: detector.example
  ↓ TCP: src port 51514, dst port 443, seq/ack, flags
  ↓ IPv4: src 192.0.2.10, dst 198.51.100.20, protocol 6, TTL
  ↓ Ethernet: src host MAC, dst next-hop MAC, EtherType 0x0800

This sanitized example works from the inside out: TCP treats the HTTP bytes as payload, IP treats the TCP segment as payload, and the local link treats the IP packet as payload. The receiver removes each header in reverse. A client-side capture can see the host and gateway MACs; after a router, a capture sees different link addresses. NAT may also rewrite the IP/port tuple, while a proxy terminates one connection and creates another. TCP adds ports, sequence, and flags; IP adds routing addresses/TTL; Ethernet adds local MAC/EtherType. QUIC uses UDP, while loopback and tunnels need not use Ethernet at all.

Interpret the capture pointA SYN at the client proves the client stack emitted a segment. A SYN at the server proves it reached that observation point. Neither alone proves TLS completed, the HTTP message was parsed, or the origin generated a response.

Visibility limits

Hosts see their own plaintext; TLS terminators see plaintext at termination; passive observers may see IP/transport and some handshake metadata, not encrypted HTTP. NAT, tunnels, loss, sampling, and clock skew constrain evidence.

Use actual boundaries

Say “DNS response at resolver” or “TCP retransmit at host capture,” not merely “Layer 7.” This preserves encryption and collection context.

Evidence workflow

  1. Name the claim.
  2. Choose the collector closest to it.
  3. Record proxy/NAT/TLS transformations.
  4. State alternatives.

Safety

Use diagrams, synthetic fixtures, loopback, or traffic you own. Do not capture shared networks, scan hosts, or expose credentials; packet privileges reveal sensitive traffic.

Detection scenarios

Origin shows no request

A SYN does not prove HTTP reached origin; separate TCP, TLS, proxy, and app evidence.

One IP has many accounts

NAT/proxy are false-positive alternatives.

DNS data disappears

Encrypted DNS changes passive visibility claims.

MAC rule crosses subnets

MAC is link-local and rewritten.
