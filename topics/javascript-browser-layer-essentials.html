Why it matters

Browser code runs with page context and can inspect only APIs exposed to that origin/browser policy. Understanding data flow makes a detection probe auditable without treating it as magic.

Values and control flow

Primitives include strings, numbers, booleans, null, undefined, bigint, and symbol. Use strict equality, explicit null handling, arrays, conditionals, and loops; JavaScript coercion can make implicit comparisons misleading.

Objects and JSON

Objects map keys to values; arrays are ordered objects. JSON.stringify serializes supported values for a request, but omits undefined properties and is not a privacy/security filter.

Functions and closures

Functions are values; an inner function can retain outer bindings (closure). When reading a probe, identify captured configuration, mutable state, event handler, and return value rather than assuming global behavior.

Promises and async

async function collect() { const value = await Promise.resolve("synthetic"); return { value }; }

async returns a Promise; await resumes later. Handle rejection deliberately. Timing/order affects telemetry; do not assume an async fetch completed before navigation without lifecycle design.

DOM and events

The DOM represents page nodes. Event listeners receive user/browser events; they should be narrowly scoped, removable where appropriate, and never record more than a documented first-party purpose requires.

Fetch sends an HTTP request

fetch("/telemetry", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ kind: "local-demo" }) })

Use a same-origin local endpoint and minimal payload. Fetch does not make a request authorized; server validates session, CSRF/origin policy, schema, size, and rate. Do not send secrets, raw fingerprints, or opaque vendor telemetry by default.

What a page script can access

It can access DOM, location, approved Web APIs, its origin storage/cookies subject to flags, and browser-exposed properties. It cannot read arbitrary local files, other-origin DOM/storage, HttpOnly cookies, or server/CDP state directly.

Same-origin, CSP, privacy

Same-origin constrains cross-origin reads; CORS is server-granted browser sharing, not authorization. CSP can constrain script source/connect destinations. Consent, data minimization, retention, accessibility, and privacy policy still govern permitted collection.

Minimal owned AbuseGuard probe

Collect one consented low-risk first-party field such as feature availability, display a notice, POST only a schema version and boolean to local /telemetry, and record server validation. Avoid stable identifiers or covert collection.

Defensive scenarios

Probe event missing

Trigger: no telemetry. Artifact: local browser console/network log. Observation: CSP blocked endpoint. Reasoning: policy boundary. Limit: absence does not prove automation.

Unexpected field

Trigger: schema mismatch. Artifact: sanitized server rejection. Observation: outdated page. Reasoning: versioned validation. Limit: not an attack verdict.

Async race

Trigger: navigation drops request. Artifact: test timeline. Observation: unawaited promise. Reasoning: lifecycle fix. Limit: network timing varies.

Browser API unavailable

Trigger: feature false. Artifact: capability matrix. Observation: privacy/browser setting. Reasoning: graceful fallback. Limit: not a bot label.
