01 · Purpose

Typing makes an evidence contract visible

Detection pipelines translate untrusted input into structured events, then into rules and outputs. A useful annotation names which values may be absent, which transformations return failures, and which interfaces a dependency must provide—before an incident path reaches production.

REVIEW

Shape is explicit

dict[str, str] and dict[str, object] make materially different promises.

REFACTOR

Call sites are checked

Changing a parser return type lets a checker find consumers that still assume the old shape.

BOUNDARY

Runtime remains real

JSON, environment variables, and network payloads require actual validation before they receive a trusted type.

DISCIPLINE

Find uncertainty

Any, casts, and ignores are debt markers to inspect, not permissions to stop thinking.

03 · Core syntax

Use modern, concrete annotations

from dataclasses import dataclass
from collections.abc import Iterable

@dataclass(frozen=True)
class Event:
    source_ip: str
    status: int

def count_errors(events: Iterable[Event]) -> int:
    return sum(event.status >= 500 for event in events)

def labels(event: Event) -> dict[str, str]:
    return {"source_ip": event.source_ip, "status": str(event.status)}
list[str], dict[str, int]

Describe parameterized containers.Use concrete key/value types at trusted boundaries. It assumes the container contents conform; the runtime does not enforce insertion types.

Iterable[Event]

Accept any one-pass or reusable event source.Use it when only iteration is required. Do not annotate list if the function need not index, mutate, or reuse the source.

@dataclass(frozen=True)

Model a small record with named fields.Useful after validation. Frozen prevents ordinary reassignment but does not recursively freeze nested mutable values.

04 · Absence

None is a value; a missing key is a different state

from typing import TypedDict

class RawLogin(TypedDict, total=False):
    user_id: str          # may be absent
    device_id: str | None # if present, may explicitly be null

def device_label(raw: RawLogin) -> str:
    if "device_id" not in raw:
        return "not-provided"
    if raw["device_id"] is None:
        return "explicit-null"
    return raw["device_id"]

Optional[T] is spelling for T | None; it does not mean “argument may be omitted.” Use a default parameter for an omitted argument, and distinguish absent JSON fields from explicit JSON null where your event contract needs both. Narrow before using a union member.

05 · Interfaces

Type what you require, not a whole implementation

from collections.abc import Callable
from typing import Protocol

Predicate = Callable[[Event], bool]

class EventSink(Protocol):
    def emit(self, event: Event) -> None: ...

def deliver(events: Iterable[Event], accept: Predicate, sink: EventSink) -> None:
    for event in events:
        if accept(event):
            sink.emit(event)

Callable[[Event], bool] describes a function-like rule with that signature. A Protocol uses structural typing: an object need not inherit from it, but must provide compatible members. This makes a production sink and a test fake interchangeable without coupling the core to a vendor SDK.

06 · Control flow

Prove a union branch before using it

def normalized_status(value: int | str | None) -> int | None:
    if value is None:
        return None
    if isinstance(value, int):
        return value
    if value.isdecimal():
        return int(value)
    return None

isinstance, is None, membership checks for typed dictionaries, and explicit return paths let a checker narrow a union. Prefer validation functions that return a trusted model or a deliberate error; do not use cast() to pretend unvalidated external input is safe.

07 · Static workflow

Run the checker, then inspect each finding

# pyproject.toml: pin tool behavior with your project
[tool.mypy]
python_version = "3.11"
warn_unused_ignores = true
check_untyped_defs = true

# Shell: use the project environment and target a package deliberately
python -m mypy src/analyzer

Use a pinned mypy version in project dependencies or CI; flags and inference evolve. python_version describes the code you target, not necessarily the interpreter executing mypy. On Windows, invoke the same Python command in PowerShell; shell activation syntax differs, but mypy’s configuration semantics do not.

Review, do not obey blindlyA finding can reveal a real defect, an incomplete third-party stub, or an intentionally dynamic boundary. Fix the code or contract where possible. If an ignore is justified, make it narrow (# type: ignore[error-code]), explain it in review, and keep warn_unused_ignores enabled so stale debt is visible.

08 · Limits & safety

Types reduce classes of mistakes; they do not validate reality

Trap Why it fails Response
Any spreads Operations are permitted without useful checking. Contain it at an adapter, validate into a typed model, and record remaining Any boundaries.
Broad ignore Suppresses unrelated future mistakes on that line. Use error-code-specific ignores; remove them when stubs or code improve.
Type annotation as validation Python normally accepts wrong runtime values. Parse and validate untrusted input; test error paths.
Incorrect config Checker scope/version differs locally and in CI. Commit config, pin tool versions, and show the exact invocation.
Secret-bearing types in logs Helpful representations can expose tokens/PII. Redact at the logging boundary; types do not classify or protect data automatically.

09 · On the job

Detection-engineering scenarios

PARSER

Schema change makes device ID nullable

Change the raw contract to str | None, let the checker find string-only consumers, and decide per detection whether absence is a missing signal, a neutral value, or a rejection.

RULES

Vendor SDK client blocks tests

Define the small Protocol the rule needs, then use a fake that records emit calls. The test proves your code’s interaction without pretending an integration has happened.

MIGRATION

Refactor changes an event field

Run the checker on the complete package and inspect each caller. A clean report complements tests; neither proves that a live upstream has honored the new field contract.

QUALITY

Ignore count rises each sprint

Treat ignores and Any as a visible risk inventory. Prioritize boundaries that feed enforcement or high-confidence detections, rather than pursuing a decorative “zero errors” metric.
