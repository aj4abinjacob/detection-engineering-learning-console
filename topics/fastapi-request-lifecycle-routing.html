01 · Purpose

Routes are the application’s observable perimeter

Register, login, and product routes become authentication, validation, persistence, and telemetry boundaries. A lifecycle diagram prevents invisible work from leaking across them.

ROUTING

ASYNC

02 · Lifecycle

ASGI server accepts HTTP, creates scope/receive/send.
→
FastAPI matches route, resolves dependencies/validation.
→
Handler calls application/repository, returns response.

Exceptions/middleware/response serialization occur around this path. Exact middleware ordering and server behavior depend on FastAPI/Starlette/Uvicorn versions—test the deployed stack.

03 · ASGI versus WSGI

WSGI is a synchronous callable interface traditionally used for HTTP request/response. ASGI is an asynchronous interface with scope, receive, and send, supporting HTTP and long-lived protocols. FastAPI is ASGI. ASGI does not make blocking database/file/network calls safe inside async def; use an async-capable library or an intentional worker/thread boundary. WSGI applications can be adapted, but adapter behavior/lifecycle is not identical.

04 · Path operations

from fastapi import FastAPI, HTTPException
app = FastAPI()

@app.get("/route-demo/products/{product_id}")
def route_demo_product(product_id: int):
    item = {"id": product_id, "name": "lab product"}
    if product_id != 1: raise HTTPException(status_code=404, detail="not found")
    return item

Use: this intentionally separate /route-demo/... path demonstrates method/path/type contracts without colliding with the repository-backed route below. Assumption: route precedence and parameter conversion match the versioned framework. Risk: do not expose internal identifiers/details in errors; a 404 is not an authorization gate—enforce ownership after identity is established.

05 · Dependency injection

from fastapi import Depends
def get_repository():
    return repository  # replace with request-scoped lifecycle where needed
@app.get("/products/{product_id}")
def product(product_id: int, repo=Depends(get_repository)):
    return repo.get_product(product_id)

Use: inject configuration, authenticated principal, repository, and request-scoped resources so tests can override them. Risk: a dependency is code executed for the request; avoid hidden network calls, global mutable state, or secrets in dependency errors.

06 · Request and response objects

FastAPI can bind path/query/header/cookie/body inputs and serialize return values. Prefer declared response models/status codes for a stable contract. Use raw Request/Response only when you need lower-level access (templates, cookies, headers); bypassing response-model validation can bypass a useful output guard.

07 · Sync and async behavior

FastAPI runs normal def path operations/dependencies in an external threadpool, while async def runs on the event loop and should await nonblocking work. This is a framework/runtime implementation detail worth checking in current docs. Choose based on library I/O model; do not mark every function async or call blocking SQLite/network APIs directly in a hot async handler.

08 · Route event contract

{"request_id":"lab-r20","method":"POST","route":"/login","status":401,
 "duration_ms":4.8,"principal":"none","outcome":"invalid_credentials"}

Use route template—not raw unbounded path—as a metric dimension; record normalized outcome and trusted client source. Never log request passwords, session cookies, authorization headers, or full bodies.

09 · Safety

Development server is not deploymentUse local development only for drills. Production needs a supported ASGI server, trusted-proxy policy, timeouts, limits, TLS termination, logging controls, and a deployment-specific security review.

10 · Detection scenarios

LOGIN

Login failures rise

Route template, outcome, trusted identity source, and latency distinguish invalid credentials from a broken dependency.

BLOCKING

Async product route stalls

Trace blocking repository calls in async def; choose compatible I/O or controlled offload.

AUTHZ

Product ID exists but is not owned

Route matching proves only syntax. Inject principal and enforce object authorization in service/repository policy.

TEST

Global database leaks test state

Override repository dependencies with disposable test implementations; do not mutate shared environments.
