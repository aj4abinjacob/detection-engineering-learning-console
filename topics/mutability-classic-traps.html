01 · Purpose

Why mutability is an operational concern

A detector often builds nested event structures, queues them, enriches them, and sends them to multiple sinks. Shared mutable state turns those stages into hidden writers of the same evidence.

ISOLATION

No cross-alert state

Each invocation must get its own accumulator, labels, and context.

PROVENANCE

Raw stays raw

Copy only at explicit normalization/redaction boundaries.

SECURITY

Secrets do not leak sideways

A reused mutable default can carry a token or tenant field into another record.

SCALE

Copies have a cost

Deep copying large event trees can consume CPU and memory under load.

02 · Mental model

Immutability is about changing the object, not its neighbors

Container A tuple can be immutable: its slots cannot be reassigned. (headers, status)
contains →
Nested object A list inside it may still be mutable. ["suspicious"]
changed by →
Alias Any holder of the nested list sees the edit. tags.append(...)

“Immutable container” does not mean “deeply immutable graph.” State safety requires examining every reachable mutable object that may be shared.

tags = ["new"]
event = ("r-7", tags)     # tuple slots cannot change
tags.append("review")     # nested list can change
print(event)               # ('r-7', ['new', 'review'])

Use: choose immutable values for stable keys, configuration, and value objects. Assumption: callers will not reach mutable nested members. Risk: treating a tuple as a deep snapshot can still alter historical evidence.

03 · Choose the right state holder

Common mutable and immutable types

Usually immutable Usually mutable Practical implication
int, float, bool, str, bytes list, dict, set, bytearray “Changes” to immutable values make/rebind a value; mutating methods edit shared objects.
tuple, frozenset Most user instances (unless designed otherwise) Tuple/frozenset are hashable only if their contents are hashable.
Recommendation, not magicUse immutable scalar identifiers and replace whole values when feasible. Use mutable collections for intentional accumulation inside one clearly owned scope. Do not confuse a type annotation such as Mapping with a runtime guarantee that nobody else mutates its underlying dictionary.

04 · The classic trap

Function default expressions run once, at definition time

def add_indicator(indicator: str, seen: list[str] = []):
    seen.append(indicator)
    return seen

print(add_indicator("ip"))      # ['ip']
print(add_indicator("domain"))  # ['ip', 'domain'] — surprising shared list

The list expression is evaluated when Python executes the def, not for each call. Every call that omits seen receives the same list. This is deterministic, not a Python bug.

from typing import Final, TypeAlias, cast

class _Unset:
    __slots__ = ()

_UNSET: Final = _Unset()
Limit: TypeAlias = int | None

def add_indicator(indicator: str, seen: list[str] | None = None) -> list[str]:
    if seen is None:
        seen = []
    seen.append(indicator)
    return seen

def read_limit(limit: Limit | _Unset = _UNSET) -> Limit:
    if limit is _UNSET:
        return 100
    return cast(Limit, limit)  # narrow away the private sentinel type

Use: None when it cannot be a legitimate supplied value; use a private sentinel when “not supplied” must differ from meaningful None. The named union and explicit narrowing preserve that distinction for a static checker instead of collapsing the annotation to object. Assumption: callers do not need to share a list intentionally. Risk: do not expose or compare a private sentinel by equality; retain its identity semantics.

from dataclasses import dataclass, field

@dataclass
class Alert:
    indicator: str
    tags: list[str] = field(default_factory=list)  # calls list per instance

Use: default_factory for dataclass mutable defaults. Risk: tags: list[str] = [] is rejected by modern dataclasses because it would be shared; a factory must not itself return a global mutable object.

05 · Copy boundaries

Shallow copy duplicates one layer; deep copy recursively duplicates reachable state

import copy

raw = {"request": {"headers": {"authorization": "secret"}}, "tags": ["auth"]}
shallow = raw.copy()       # or {**raw}; nested dict/list are shared
deep = copy.deepcopy(raw)  # recursively copies normal nested objects

shallow["tags"].append("review")
print(raw["tags"])        # ['auth', 'review']
deep["tags"].append("isolated")
Operation What it makes When appropriate Risk
list(x), dict(x), x.copy() New outer container Top-level metadata change Nested state remains shared.
copy.copy(x) Shallow copy via protocol Generic code with documented types User types can customize it.
copy.deepcopy(x) Recursive copy with memo for cycles Small, known, in-memory data snapshots Costly; may copy too much or invoke custom hooks.
Explicit reconstruction Only selected fields Telemetry/schema boundaries Must deliberately cover required fields.

deepcopy does not copy every external resource meaningfully: modules, sockets, files, database connections, locks, and framework objects may be returned unchanged, fail, or have custom behavior. It honors __copy__, __deepcopy__, and pickling-related hooks on custom classes. Treat it as an API contract review, never as a generic security scrubber.

06 · Safety and performance

Copy only the data you mean to own

new_event = {**raw, "source": "edge"}

Copy an outer event mapping.Use for a top-level enrichment. Assumes nested fields will not be mutated; otherwise rebuild those fields explicitly.

field(default_factory=list)

Allocate per dataclass instance.Use for intentional per-alert collections. Assumes the factory returns a fresh value every time.

copy.deepcopy(value)

Request recursive duplication.Use only with a bounded, understood value graph. It can expose sensitive data in a duplicate, trigger custom code, and amplify memory use.

python3 -m timeit -s 'import copy; x=...' 'copy.deepcopy(x)'

Measure a representative copy in a local lab.Use sanitized bounded fixtures; timing varies by machine and does not predict production queues alone.

Security boundary warningCopying a record is not redaction. A deep-copied authorization header remains a secret in another object, potentially another queue or log. Select and transform allowed fields; do not duplicate then hope every downstream sink filters them.

07 · On the job

Detection-engineering scenarios

MULTI-TENANT

One tenant inherits another tenant’s label

An alert builder uses tags=[] as a default. A high-risk tag from the first event appears in the next tenant’s alert. Reproduce with two calls, replace the default with None or default_factory, then add a regression test.

FORENSICS

A normalized event changes nested raw headers

A shallow copy is redacted by editing normalized["headers"]. The nested map is shared, so raw evidence changes too. Explicitly rebuild the header map and retain the unmodified source under access controls.

THROUGHPUT

A batch worker deep-copies every large event

Recursive copies turn a traffic spike into memory pressure and higher queue latency. Profile with sanitized representative payloads, then use immutable parsing or an explicit, minimal output schema instead.

INTEGRATION

A framework object refuses to deep-copy

A request or client object contains sockets, locks, and lazy state. Do not fight its copy protocol; extract the documented primitive fields needed for a detection event, then close/handle resources through their intended lifecycle.
